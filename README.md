# AI 动态聚合 · 实时看板

一个纯前端（无后端）的 AI 资讯聚合看板，浅色主题 + 蓝紫主色 `#3D35F2`。

## 数据来源

| 板块 | 数据源 | 说明 |
| --- | --- | --- |
| 精选 / 全部动态 / 热点榜 / 日报 | [AIHOT](https://aihot.news/) 公开只读 API | 运行时实时拉取，无需 Key |
| 竞品动态 | [ai-video-watch](https://tarma945-debug.github.io/ai-video-watch/) | 运行时抓取 26 家 AI 视频站点、234 条更新 |
| 模型榜单（视频 / 图片） | 本地 `data.js` | 静态数据，手工维护 |

## 特色

- **8 个页面**：精选、全部动态、热点榜、日报、竞品动态、AI 模型总榜、视频模型榜、图片模型榜
- **链接可用**：每条资讯同时给「AIHOT 站内」和「原文」两个链接，点进去能看到正文
- **日报含竞品动态**：日报页内嵌竞品更新板块，当天不足 3 条时自动回退到近 7 天精选
- **竞品时间线**：默认「全部」按日期倒序分组，也可按单站点查看
- **双层缓存**：内存 + localStorage（5 分钟 TTL），请求去重，失败回退旧缓存并标记 stale
- **响应式**：PC 与 390px 移动端都做过几何审计（无横向溢出、无文字裁切、点击区 ≥ 34px）

## 本地打开

```bash
# 直接双击 index.html 也可以（AIHOT 与 ai-video-watch 都返回 CORS *）
# 或者起个静态服务器：
python3 -m http.server 8000
```

## 文件结构

```
index.html   页面骨架
styles.css   全部样式（CSS 变量控制主题）
app.js       全部逻辑（路由 / 数据 / 渲染）
data.js      本地模型榜单数据
```
